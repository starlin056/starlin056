## Perfil

Desarrollo soluciones de software para **gestión empresarial, ventas, inventarios y control de operaciones**, conectando las necesidades del negocio con la implementación técnica. Mi trabajo comprende sistemas POS, plataformas para restaurantes, gestión de turnos, seguimiento de incidencias y aplicaciones para pequeñas y medianas empresas.

Mi stack combina **PHP y Laravel** para backend, **React, JavaScript y TypeScript** para interfaces, y **Python** para automatización y procesamiento de datos. También trabajo con bases de datos relacionales y aplicaciones móviles híbridas mediante Ionic y Angular.

Mis áreas de interés incluyen **arquitectura modular, plataformas SaaS, integración de APIs y modernización de sistemas existentes**. Oriento el desarrollo hacia la mantenibilidad, la integridad de los datos y la continuidad de los procesos operativos.

Actualmente curso la **Licenciatura en Informática Gerencial**, complementando mi formación con el desarrollo de proyectos y la mejora continua de mis prácticas de ingeniería.

## Criterios de ingeniería

Prioridades que guían el desarrollo y la evolución de mis soluciones:

- **Arquitectura mantenible:** organizar módulos, separar responsabilidades y reducir el acoplamiento entre componentes.
- **Seguridad de aplicación:** atender la validación de entradas, la autorización y el manejo de credenciales desde el diseño.
- **Integridad de datos:** cuidar las relaciones, las reglas de negocio y la consistencia de las operaciones.
- **Calidad y verificación:** comprobar los flujos críticos, fortalecer las pruebas y revisar el impacto de los cambios.
- **Rendimiento:** identificar cuellos de botella y optimizar consultas y procesos con base en mediciones.
- **Operación y mantenimiento:** documentar configuración, instalación y cambios para facilitar el soporte y la evolución del sistema.
